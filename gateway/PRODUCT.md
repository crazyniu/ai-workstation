# Gateway 网关桌面

家庭网关的一体化容器后台，服务普通家庭网络使用者。首页用于快速打开 Clash、AdGuard Home、Tailscale 和自定义其他设备入口。设置在二级窗口完成代理订阅、DNS、本地域名、Tailscale 路由、服务升级及配置备份。

现有技术：静态 HTML/CSS/JavaScript、Nginx、Python API。保留真实 API 与数据兼容。以 WinBox 作为开源窗口管理基础，不引入完整桌面操作系统。

2026-10-23 用户要求替换原深绿主题。视觉权威为用户最新上传的浅色 NAS Web 桌面截图：蓝色海岸壁纸、独立彩色图标、浅色控制面板、蓝色操作按钮、mac 风格窗口控制、桌面及图标右键菜单。所有界面控件统一设计；设置保持二级层级，桌面无大卡片、营销文字或虚构系统指标。

支持桌面和手机。配置有风险的动作保持明确确认、失败提示及现有恢复能力。用户数据只持久化至 /data，不进入构建材料。
