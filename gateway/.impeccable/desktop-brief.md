# 网关桌面重设计

Mode: Operate. 用户明确授权替换视觉，不保留旧深绿主题。

FIRST VIEWPORT: 全屏青蓝海岸照片；顶部 44–48 px 的轻量透明工具栏；左侧 68–74 px 彩色圆角应用图标纵向布局，白色名称；留白交给壁纸。打开设置后是居中的白色控制面板，浅灰标题栏、左侧三色窗口控制，分组图标总览；二级设置页为浅灰导航与白色内容，蓝色主按钮。

Signature interaction: 使用 WinBox 的真实拖动、缩放、最小化/还原；桌面空白和自定义图标拥有不同的右键菜单，手机长按可达；自定义图标拖动排序保存到 API。

参考截图指定气氛、层级、色彩与窗口结构，不复制截图中的 NAS 专属功能和品牌。壁纸采用可再分发来源或原创资产，记录来源。图标自绘 SVG，同一视觉系统。

响应式：桌面窗口 1040 × 740 上限；手机窗口铺满视口，表单 16 px，触控目标至少 44 px，内容独立滚动。检查 1280 × 720 和 390 × 844 的实际浏览器结果。

验收：真实 API 的图标添加/修改/删除/排序；设置所有页面可达；自绘下拉、复选框、文件入口和确认弹窗；壁纸选择/填充方式保存；控制面板关闭/最小化/还原；键盘和手机不溢出。
