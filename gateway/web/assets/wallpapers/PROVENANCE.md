# Default wallpapers

`coast` retains the previously approved original gateway wallpaper at `/assets/coast-wallpaper.webp`; its existing generation metadata remains beside that file.

`mountain.png`, `dusk.png`, and `forest.png` are original landscape assets created with the built-in OpenAI image generation tool on 2026-10-23. Each file has a sidecar with its prompt, dimensions, SHA256, and provenance. No stock photographs, remote image URLs, private data, brand marks, or third-party wallpaper downloads are included. These generated assets are distributed as project artwork under the repository's license.

All four wallpapers are local, landscape images selected by stable IDs in `catalog.json`.
