你可以使用「局域网互传」HTTP 接口操作网关上的共享文件。请在能访问网关的设备上使用 curl 或 HTTP 客户端，无需账号、密码或 Cookie。只执行用户要求的操作。下面是独立的用法示例，请勿整段执行。

网关地址：http://192.168.1.250
路径相对于共享根目录。用 / 分隔子目录，包含中文、空格、# 等字符时，对整个 path 参数做一次 UTF-8 URL 编码。先创建父目录。同名上传返回 409，不会覆盖已有文件。出错时读取 HTTP 状态和 JSON 中的 error。

以下示例使用同一组 shell 变量和函数：
base='http://192.168.1.250/api/transfer'
enc() { python3 -c 'import sys, urllib.parse; print(urllib.parse.quote(sys.argv[1], safe=""))' "$1"; }

列根目录：curl -fsS "$base/list"
列文件夹：curl -fsS "$base/list?path=$(enc '收件箱')"
列表返回 entries，每项有 name、type（file 或 folder）、size（文件字节数）。

建文件夹：curl -fsS -X PUT "$base/folder?path=$(enc '收件箱')"
上传文件：curl -fsS -T './报告.pdf' "$base/file?path=$(enc '收件箱/报告.pdf')"
下载文件：curl -fS -o './报告.pdf' "$base/file?path=$(enc '收件箱/报告.pdf')"
删除单个文件：curl -fsS -X DELETE "$base/file?path=$(enc '收件箱/报告.pdf')"
删除文件夹及其全部内容：curl -fsS -X DELETE "$base/folder?path=$(enc '收件箱')"
清空整个共享区（包括所有子文件夹）：curl -fsS -X DELETE "$base/all"

单次上传请求最多 32 MiB。更大的文件按以下 Python 3 示例分块，两个参数分别为本地文件、共享区目标路径：
python3 - './视频.mp4' '收件箱/视频.mp4' <<'PY'
import json, os, sys, urllib.parse, urllib.request, uuid
local, remote = sys.argv[1:]
url = 'http://192.168.1.250/api/transfer/file?' + urllib.parse.urlencode({'path': remote})
upload_id = uuid.uuid4().hex
client = urllib.request.build_opener(urllib.request.ProxyHandler({}))
with open(local, 'rb') as source:
    total = os.fstat(source.fileno()).st_size
    while True:
        start = source.tell()
        chunk = source.read(8 * 1024 * 1024)
        headers = {'Content-Type': 'application/octet-stream'}
        if total:
            headers.update({'Upload-Id': upload_id, 'Content-Range': f'bytes {start}-{start+len(chunk)-1}/{total}'})
        request = urllib.request.Request(url, data=chunk, headers=headers, method='PUT')
        with client.open(request) as response:
            result = json.load(response)
            if response.status == 201:
                print(result['path'], result['size'])
                break
PY
