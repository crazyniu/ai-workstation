账号操作

断开连接会保留登录身份；退出账号后需要重新授权。

服务升级

从官方来源获取稳定版本，校验后逐项升级。升级期间对应服务会短暂中断。

网关镜像

后台和基础系统随 Docker 镜像更新。更换镜像前先导出容器内部数据，创建新容器后恢复并验证。直接删除或重建会丢失内部数据。

桌面管理

所有桌面图标都可以拖拽排序，顺序会自动保存。也可选中图标后按 Alt + ↑ / ↓ 调整。内置入口始终保留。

工作站网页桌面

填写实际工作站的 IP 或域名，可修改协议和端口。桌面上的“工作站”图标始终使用此地址。

登录状态

备份与恢复

导出代理、DNS、桌面、订阅和 Tailscale 身份配置。

备份包含节点凭据和登录身份，请妥善保存；管理员密码不会导出。

从备份恢复

恢复会替换当前配置及 Tailscale 身份，并短暂重启服务。操作前自动保存原配置。
