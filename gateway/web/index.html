桌面管理

管理工作站入口和桌面上的自定义链接。

工作站入口

“工作站”在窗口中打开的地址。

自定义链接

显示在桌面上，默认在窗口中打开。这里的顺序也是手机主屏幕的顺序。

桌面与程序坞布局在桌面上可以把图标拖到任意位置，拖进或拖出程序坞；也可以右键图标选择。恢复默认会把网关应用放回程序坞，链接重新排在桌面右侧。

账户与安全

管理网关管理员的登录方式、密码与当前会话。

登录需要密码开启后，打开 Niu Gateway 前必须输入管理员密码。

管理员密码

用于登录 Niu Gateway；修改后其他已登录的浏览器需要重新登录。

当前会话退出后，此浏览器需要重新输入管理员密码。

备份与恢复

导出网关配置，或用备份文件恢复当前网关。

下载配置备份包含代理配置、节点凭据、Tailscale 身份与桌面设置，不含管理员密码。请妥善保管备份文件。

从备份恢复

恢复前会自动保存当前配置，随后替换网关设置并短暂重启服务。
